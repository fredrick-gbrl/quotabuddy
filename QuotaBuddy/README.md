# QuotaBuddy 2

QuotaBuddy 2 è un'app Android offline-first per gestire abbonamenti condivisi tra amici.

## Funzioni

- Più Family/abbonamenti indipendenti (Spotify, Netflix, ecc.)
- Costo mensile totale e storico dei cambi di prezzo per ciclo di rinnovo
- Divisione automatica in base ai membri attivi, con opzione per includere il proprietario
- Una persona può partecipare a più Family
- Ingresso/uscita dei membri con data di efficacia
- Pagamenti modificabili ed eliminabili
- Allocazione automatica di ogni pagamento dalla quota più vecchia scoperta verso i mesi futuri
- Gestione di arretrati, pagamenti parziali e anticipi
- Dashboard generale e dashboard per Family
- Sezione Debiti per prestiti e favori che non c'entrano con le Family, con mini dashboard del saldo netto
- Profili persona con storico
- Backup/ripristino JSON locale
- Import dei vecchi backup testuali QuotaBuddy 1
- UI dark con identità acid-lime e icona Q dedicata

Nessun account o servizio cloud è richiesto.

QuotaBuddy 2 usa un nuovo application ID, quindi può essere installato accanto alla vecchia app. Per migrare, esporta il backup da QuotaBuddy 1 e importalo da Altro → Backup.
